# Français A1 → B2 in 6 months

A day-by-day study plan (3 Nov 2026 → 3 May 2027, 4 hours a day) as a small static web app:
**https://hardil-bitdecentro.github.io/french-a1-b2/**

- **Today**: the day's checklist in three sessions, with minutes, links and copy-ready Claude prompts.
- **Plan**: all 182 days by week, with progress.
- **Mistakes**: the error log from every day, plus backup / restore of progress.
- **Materials** and **Method**: the book, course, YouTube, Anki setup, memory schedule, targets.

Progress is stored in the browser (`localStorage`); nothing is sent anywhere.

## Develop

```sh
npm install        # also installs the pre-commit hook (husky + lint-staged → prettier)
npm run serve      # http://localhost:8765
npm test           # vitest
npm run format:check
```

The schedule lives in `site/data/schedule.json`, generated by `scripts/make_schedule.py` (`npm run schedule`).
Push to `main` → CI (format + tests in parallel) → deploy to GitHub Pages.
